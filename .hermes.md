# Fiction Workshop

This repository owns a project-local fiction-development skill and story state.

## Operating rules

- Load `story-development` for fiction brainstorming, outlining, drafting, revision, continuity review, or expansion.
- Treat `stories/*/release-contracts/*/` as immutable snapshots. Never edit them in place.
- Use the same kernel, canon, lineage, and obligation model at every story length; activate additional artifacts progressively.
- Keep `SKILL.md` procedural and concise. Put detailed models and rubrics in its `references/` files.
- Use JSON for deterministic state and Markdown for prose, plans, decisions, and editorial evidence.
- Run `python3 -m unittest discover -s tests -v` and validate every fixture before committing.
- Only original fiction belongs under `stories/`; derivative work based on a
  third party's fictional setting stays outside this repository.
- Every `stories/*/` directory carries a nonempty `LICENSE.md` naming its
  copyright owner and terms.
- Do not copy copyrighted passages or instruct a model to impersonate a named author. Translate influences into abstract craft dimensions.
- Re-gate before adding shared canon across story slugs, a database, retrieval service, custom UI, publishing automation, or multi-agent orchestration.
