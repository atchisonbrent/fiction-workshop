# Story licensing

Examples in this directory are original creative works and are **not** covered by
the repository's MIT license.

Every `examples/<slug>/` directory must contain a `LICENSE.md` naming the example's
copyright owner and terms. Unless that per-example file grants additional rights,
the prose and story-specific creative assets are all rights reserved.

Personal story projects belong in a separate content repository so cloning this
tooling repository does not download them. Do not add derivative works based on
third-party fictional settings or copied source material here.
